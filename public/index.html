HEXOPS

Playable single-file games on the hex-map-wfc cube lattice.

  • HOLD — maze maker + tower placer + walking waves (the TD engine)
  • HEXOPS — mines / yield / hold in one page
  • KINFIELD — inverse mines: place related kin

Jev harness (Python) lives in the repo root: python -m harness.cli --world hex --mode mock
